# Milestones

## Milestone 0: análisis del problema de la HU001

Es un milestone interno. Trabaja con el
problema de la [HU001](historias_de_usuario.md#hu001-no-sé-si-vender-la-almendra-esta-semana-o-esperar-a-las-siguientes)
y para analizarlo se sigue diseño dirigido por el dominio (Domain Driven Design).

Es válido si se ha seguido la metodología. Lo compruebo viendo que:
- todo lo que hay en el código sale de la HU001, y con eso ya se puede
  empezar a programar la lógica del milestone 1.

## Milestone 1: código que resuelve el problema de la HU001 comprobada con tests

Es un milestone interno: lo que se entrega lo usa el equipo para seguir desarrollando
y todavía no le llega al cliente, así que se valida con los tests. Parte de lo que se entrega en el
milestone 0 y sigue con el problema de la [HU001](historias_de_usuario.md#hu001-no-sé-si-vender-la-almendra-esta-semana-o-esperar-a-las-siguientes), dividiéndolo en
problemas más pequeños que se puedan comprobar con un test.

Es válido si todos los tests pasan: cada uno comprueba uno de esos problemas
más pequeños y, entre todos, el problema de la HU001.
